# Policy di conservazione - matrice da approvare

> Nessun periodo viene dichiarato “a norma” in automatico. Il Titolare/DPO deve approvare tempi proporzionati alle finalità.

| Categoria | Default progettuale | Periodo definitivo |
|---|---|---|
| Termini di ricerca cittadino | Non memorizzare | 0 |
| Cronologia individuale visite | Non creare | 0 |
| Analytics | Solo aggregati | [definire] |
| Log tecnici hosting | Minimo necessario a sicurezza/troubleshooting | [definire con provider] |
| Sessioni operatori | Durata tecnica strettamente necessaria | [definire] |
| Audit modifiche admin | Necessario per accountability e contestazioni | [definire] |
| Segnalazioni | Fino a risoluzione + periodo giustificato | [definire] |
| Backup | Rotazione documentata | [definire] |
| Export a fine contratto | Finestra concordata | [definire] |

## Cessazione del servizio

Alla cessazione devono essere documentati:
- data di stop sincronizzazioni;
- revoca accessi;
- export/restituzione;
- cancellazione ambiente operativo;
- scadenza backup residui;
- evidenza finale di cancellazione/restituzione.
