# Dove Riposa — MVP

Prototipo dimostrativo di un motore federato nazionale per la ricerca delle sepolture.

## Avvio locale

npm install
npm run dev

## Nota dati/privacy

Il progetto contiene esclusivamente dati demo fittizi. Prima di un utilizzo con dati reali occorre definire con ciascun ente: titolarità/responsabilità, fonti e licenze, basi di trattamento/riuso, sicurezza, conservazione, rettifica, eventuale DPIA/DPO e contratti applicabili.
